# Расписание ННГУ → календарь

Зеркало расписания группы **4523С1СТ3** в формате iCalendar.

Подписка:

```
https://GITHUB_USER.github.io/unn-rasp/schedule.ics
```

## Зачем зеркало

Портал отдаёт `.ics` по адресу
`https://portal.unn.ru/ruzapi/schedule/group/52664.ics`, но:

- без query-строки — это только текущая неделя;
- весь семестр доступен лишь через `?start=…&finish=…`, а такой URL
  не принимает диалог «Подписной календарь» в iOS.

`build.py` забирает полный диапазон и кладёт результат в `schedule.ics` —
адрес получается коротким, без query, и iOS его принимает.

Верхнюю границу `finish` портал ограничивает и **сам называет свой предел**
в тексте ошибки 422. Скрипт спрашивает её каждый раз, поэтому дату
не нужно править вручную при смене семестра.

Обновляется GitHub Action каждые 6 часов.
